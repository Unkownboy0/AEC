# Phase 9 – Role-Based Dashboard Matrix Report

## Overview
This document specifies the executive dashboard view permissions across all 11 core roles in GEETORUS CAMPUSOS.

---

## Role-Based Dashboard Scope Matrix

| Role | Dashboard Scope | Primary Focus / Metrics |
|---|---|---|
| **Super Admin** | Campus-Wide System | User Activation, Login Activity, Security Audits, Storage, Queue Health |
| **Principal / VP** | Institution-Wide Executive | Total Students/Faculty, Campus Attendance %, Pass %, Leave Trends |
| **Academic Dean** | Academic Operations | Subject Pass %, Faculty Workload, Timetable Coverage, Academic Tasks |
| **HOD** | Department Scoped | Department Student/Faculty Counts, Department Attendance %, Result Trends |
| **Faculty** | Assigned Workload | Assigned Classes/Sections, Weekly Lecture Slots, Own Leave Balance |
| **Mentor** | Assigned Mentees | Mentee Attendance %, Academic Performance Flags, Leave Records |
| **Student** | Self Profile | Personal Attendance %, Internal Marks, CGPA, Leave History |
| **Parent** | Linked Children | Linked Child Attendance %, Result Trends, Fee Dues |
