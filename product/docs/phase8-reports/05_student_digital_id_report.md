# Phase 8 – Student Digital ID Specification Report

## Overview
This document specifies the CR80 ID-1 standard physical layout, fields, and rendering pipeline for Student Digital ID Cards.

---

## 1. Physical Specifications
- **Standard Ratio**: CR80 ID-1 (85.60 mm × 53.98 mm)
- **Output Format**: Vector PDF & High-Res PNG
- **Theme Palette**: Slate & Indigo Theme (`#0f172a`, `#4f46e5`)

---

## 2. Card Layout Components
- College Logo & Institutional Header
- Student Photo Box
- Student Full Name, Register/Admission Number
- Department & Program Codes
- Blood Group Indicator
- Non-sensitive Verification QR Code
- Transparent Principal Signature Asset & Expiry Notice
