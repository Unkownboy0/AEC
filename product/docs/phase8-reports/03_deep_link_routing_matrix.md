# Phase 8 – Deep-Link Routing Matrix Report

## Overview
This document specifies structured mobile deep-link URIs mapped to target screens across GEETORUS CAMPUSOS.

---

## Deep-Link Routing Matrix

| Related Entity Type | Deep-Link URI Format | Target App Screen |
|---|---|---|
| `STUDENT_LEAVE_REQUEST` | `campusos://leave/student/:id` | Student Leave Request Details Screen |
| `FACULTY_LEAVE_REQUEST` | `campusos://leave/faculty/:id` | Faculty Leave Request Approval Screen |
| `INSTITUTIONAL_CIRCULAR` | `campusos://circulars/details/:id` | Circular Viewer Screen |
| `TASK` | `campusos://tasks/details/:id` | Task Details & Workboard Screen |
| `SECURITY_AUDIT` | `campusos://security/audits` | Security Console |
| Default Fallback | `campusos://notifications` | Notifications Console |
