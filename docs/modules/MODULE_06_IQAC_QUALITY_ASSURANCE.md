# Module 06 — IQAC / Quality Assurance

## Canonical workspace

All IQAC role variants use the same live workspace and versioned Evidence Repository. The removed documentation mock is no longer routed. Supported frameworks are NAAC, NBA, AQAR, SSR, Academic and Administrative Audit, Annual Reports, Best Practices and Institutional Values.

## Evidence lifecycle

1. IQAC creates a framework audit with criteria/indicator/metric requirements, departments and deadlines.
2. Evidence tasks may be assigned through the shared Task engine.
3. Contributors upload a new repository item or reference an authorized source. The current version is unique per audit, department and requirement.
4. IQAC places evidence under review, verifies it, rejects it, or returns it for correction with mandatory remarks.
5. Resubmission creates a new version and preserves earlier records.
6. Comments, verification changes and task assignments enter the audit timeline and security audit log.

`repositoryKey`, `sourceType` and `sourceEntityId` implement Upload Once → Reuse Everywhere without copying domain datasets. Supported provenance includes Faculty Appraisal, Research, Patent, Event, Placement, Student Metric, Feedback and ATR sources.

## Boundaries

IQAC managers can request, assign and verify. HOD and Faculty contributors can see only audits/evidence for their assigned departments and cannot verify. Admission Dean, Academic Dean and COE workspaces are not accepted. IQAC ⇄ Faculty switching remains available only through explicit active workspace assignment and a linked Faculty profile.
